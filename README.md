# 📋 Cadastro de Usuários
 
Aplicação full-stack para cadastro e listagem de usuários, com back-end em **Node.js/Express + MongoDB** e front-end em **React + Vite**.
 
## 🚀 Funcionalidades
 
- ✅ Cadastro de novos usuários (nome, email e idade)
- ✅ Listagem de usuários cadastrados
- ✅ Avatar gerado automaticamente para cada usuário
- ✅ Persistência dos dados no MongoDB
## 🛠️ Tecnologias utilizadas
 
**Back-end**
- Node.js
- Express
- Mongoose (MongoDB)
- CORS
- dotenv
**Front-end**
- React
- Vite
- Axios
